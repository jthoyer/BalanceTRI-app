Buttons

All interactive controls keep a 44px minimum height/width for touch targets. Buttons are borderless with color and weight doing the differentiation.

Primary & secondary

Primary is the single highest-emphasis action per screen (e.g. add / save / create). Secondary is for the paired dismiss action.

<button class="primary-button">Add a race <span>+</span></button>
<button class="secondary-button">Cancel</button>
<button class="text-button">Refresh</button>
<button class="icon-button" aria-label="Close">×</button>

Choice pills

Used for event/distance selection and commitment level. Selected state has a neutral navy style by default; the locked level gets its own green treatment so a firm commitment reads as unmistakably "done."

Commitment levels

There is no "not going" option — someone who isn't racing simply has no entry, so the roster only ever lists people who are actually in.

<button class="choice selected">Planning</button>
<button class="choice level-locked selected">Locked in</button>   <!-- green -->

Form fields

Inputs share one style across the app: 1px border, 9px radius, 44px min height, white fill — including "Race name" in the add-race form, which matches "View an athlete's races" exactly rather than falling back to browser defaults.

Components

Composite pieces built from the tokens and primitives above.

Race card — collapsed

.race-summary uses --brand-blue as its own background, independent of the ink/navy used for the page header.

Race card — expanded, with race website

Details sections run the full width and height of the card — no nested panel, no inset margin — with grey .card-header labels as the only separators. Roster entries are grouped by distance (alpha), and names within each group are alpha-sorted too. Each distance label (.roster-group-label) uses --brand-blue — the same blue as the card's own summary bar — set at the same 12px size as .card-header. Commitment level is kept separate from distance: it shows as a small pill (.roster-level) next to each name, rather than being folded into the distance grouping. In "Your commitment," each group — commitment level, participation type, and the add-a-distance field — gets its own .choice-label: the same bold/uppercase/12px treatment as .card-header, but in --brand-blue rather than grey, so it reads as a sub-heading within the section instead of another top-level header.

Feedback & states

Focus ring

Applied via :focus-visible to buttons, links, and inputs — tab to the field below to see it.

Destructive hover

Reduced motion

A global @media (prefers-reduced-motion: reduce) rule disables scroll-behavior, transitions, and animation site-wide — no per-component opt-out needed.

Radius & spacing

Every rectangular element in the app shares one corner radius. Pills are the one deliberate exception — they stay fully round (999px) as a distinct shape, not a point on the radius scale.

RadiusPreviewUsed on
9pxEverything rectangular: .hero, .race-card, .add-panel, dialog, .empty-state, .primary-button/.secondary-button, .roster-remove, .save-button, text inputs
999px (pill).choice, .old-races-toggle

Touch targets

Every interactive element (.text-button, .icon-button, .primary-button, .secondary-button, inputs, .choice, .save-button) enforces min-height: 44px for accessible tap sizing.
